# 📰 Newsletter Page

Projeto front-end desenvolvido para criar uma página de inscrição em newsletter, permitindo que usuários informem seus dados para receber atualizações e conteúdos por e-mail.

A aplicação foi construída com foco em prática de layout, formulários e estilização, utilizando apenas tecnologias básicas do desenvolvimento web.

---

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript  

---

## Estrutura do Projeto

Newleaster/
│
├── index.html
├── style.css
├── script.js
└── img/

---

## Funcionalidades

- Interface de inscrição em newsletter  
- Formulário para coleta de dados do usuário  
- Layout simples e organizado  
- Estrutura de arquivos separando **estilos, scripts e imagens**

---

## Como Executar o Projeto

Clone o repositório:

git clone https://github.com/seu-usuario/Newleaster.git

Entre na pasta do projeto:

cd Newleaster

Abra o arquivo **index.html** no navegador.

## Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos básicos de desenvolvimento web, incluindo:

- Estruturação de páginas com HTML
